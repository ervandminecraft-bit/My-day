# Мой день: приложение для iPhone

Задачи, напоминания, финансы (доллары, драмы, рубли) и заметки. Работает без интернета, данные хранятся в телефоне.

## Как поставить на iPhone (один раз, ~10 минут)

### 1. Выложи файлы на GitHub Pages (бесплатно)
1. Зайди на github.com и создай аккаунт (если нет).
2. Нажми **New repository**, назови, например, `moi-den`, оставь **Public**, создай.
3. Нажми **uploading an existing file** и перетащи **все файлы из папки** (`index.html`, `manifest.webmanifest`, `sw.js`, три `icon-*.png`). Нажми **Commit changes**.
4. Открой **Settings → Pages**. В разделе *Branch* выбери `main` и папку `/ (root)`, нажми **Save**.
5. Через 1–2 минуты появится ссылка вида `https://ТВОЁ-ИМЯ.github.io/moi-den/`.

### 2. Установи на главный экран
1. Открой эту ссылку **в Safari** на iPhone (именно в Safari, не в Chrome).
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран "Домой"»** и нажми **«Добавить»**.
4. Запускай приложение с иконки на главном экране. Оно откроется на весь экран, как обычное.

## Важно знать

- **Данные хранятся только на этом телефоне.** Раз в пару недель заходи в **Настройки (значок справа вверху) → Сохранить копию** и сохраняй файл в «Файлы» / iCloud. Из этого файла можно восстановить всё на новом телефоне.
- **Не удаляй иконку с главного экрана**: вместе с ней iOS может стереть данные приложения.
- **Напоминания:** чтобы iPhone напомнил, когда приложение закрыто, нажми на значок календаря рядом с напоминанием. Оно добавится в «Календарь» с уведомлением в нужное время.
- **Курсы валют:** в Настройках нажми «Обновить из интернета» или впиши курс вручную. Каждая операция хранится в той валюте, в которой ты её записал, а в итогах всё пересчитывается по текущему курсу.
- **Обновления приложения:** если я изменю файлы, просто загрузи новые версии в тот же репозиторий. На телефоне обновление подтянется само при следующем запуске с интернетом.
